# 하늘시계 배포 안내 (GitHub Pages)

무지개다리를 건넌 날부터 보호자의 120번째 생일까지를 하늘의 1시간으로 환산해 보여주는 웹앱입니다.
서버·로그인 없이 동작하며, 입력한 정보와 사진은 각 사용자의 기기에만 저장됩니다.

## 1. 올리기 (최초 1회, 약 10분)

1. github.com 가입 후 로그인
2. 우측 상단 `+` → `New repository`
   - Repository name: `heaven-clock` (원하는 영문 이름)
   - **Public** 선택 (무료 GitHub Pages는 공개 저장소에서 동작)
   - `Create repository`
3. 만들어진 저장소 화면에서 `uploading an existing file` 클릭
4. 이 폴더의 파일 전부(index.html, sw.js, manifest.webmanifest, 아이콘 png 4개)를 끌어다 놓고 `Commit changes`
5. 저장소 `Settings` → 왼쪽 `Pages`
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → `Save`
6. 1~2분 뒤 같은 화면 상단에 주소가 표시됩니다.
   예: `https://아이디.github.io/heaven-clock/`

참고: 저장소가 공개라서 **코드는 누구나 볼 수 있지만, 사용자가 입력한 반려동물 정보·사진은 서버로 전송되지 않고 각자 기기에만 저장됩니다.**

## 2. iPhone에 설치

1. **Safari**로 위 주소 열기
2. 아래쪽 공유 버튼 → `홈 화면에 추가`
3. 홈 화면의 '하늘시계' 아이콘으로 실행 → 정보 입력

반드시 홈 화면 아이콘으로 실행해 주세요. Safari 탭에서만 쓰면 오랫동안 방문하지 않을 때 브라우저가 저장 데이터를 지울 수 있습니다.

## 3. Android에 설치

Chrome으로 주소 열기 → 메뉴(⋮) → `홈 화면에 추가` 또는 `앱 설치`

## 4. 백업

앱을 지우거나 기기를 바꾸면 기록이 사라집니다. 앱의 `백업` 화면에서
- `백업 파일 저장`: 파일 앱 등에 저장
- `백업 코드 복사`: 메모 앱에 붙여넣어 보관

복원할 때는 같은 화면에서 파일을 고르거나 코드를 붙여넣고 `복원`을 누릅니다.

## 5. 수정해서 다시 올릴 때

1. 저장소에서 바꿀 파일을 다시 업로드
2. `sw.js` 첫 부분의 `heaven-clock-v1`을 `v2`, `v3`처럼 올려서 함께 업로드
   (그래야 이미 설치한 기기가 새 버전을 받습니다)
